# 门店打印代理 — 安装说明（随包分发版）

> 这个压缩包里是「门店本地打印代理」：装在一台**常开机的电脑**上，
> 它会自动从云端取打印任务、发给门店里的打印机。装好后**不用再管**，开机自动运行。

## 开始前需要 2 样东西

1. **管理后台地址**：浏览器打开点餐管理后台时的网址（形如 `https://dining.xxx.com`，不要带 `/prod-api` 和结尾斜杠）；
2. **代理令牌**：由总部/技术人员在管理后台「系统配置 → 小票打印 → 本地打印代理」里签发给你。

以及一台门店里**常开机、和打印机同一网络**的电脑（收银电脑、小主机、树莓派都可以）。

## 选择你的电脑系统，照做其一

### Windows（收银电脑）

1. 把压缩包解压到一个固定文件夹（建议 `D:\print-agent`，以后别删、别移动）；
2. **双击 `install.bat`** → 按提示粘贴后台地址和令牌 → 自动完成安装并注册开机自启；
3. **双击 `start.bat`** 立即启动（以后每次开机也会自动启动，无需再双击）；
4. **双击 `p.bat`** 查看状态，出现进程「运行中」且日志里有「已连接云端」即成功。

### macOS（Mac 电脑）

**最简单的做法：双击 `双击安装.command`** —— 它会问你三样东西（后台地址、令牌、打印机 IP），
然后自动装好并停住让你看结果。

偏爱命令行的，解压后打开「终端」，把文件夹拖进终端窗口回车进入该目录，执行**一条**：

```bash
./install.sh https://你的后台域名 你的令牌 192.168.1.133
#                                        ^^^^^^^^^^^^^^ 打印机 IP,可以不填
```

> 打印机 IP 在管理后台「打印机管理」里能查到。**不填也行**：程序会记住云端任务里出现过的
> 打印机地址，之后执行 `<App 内的 print-agent> --setup-cups auto` 就能自动配好
> （先在后台点一次「测试打印」即可）。

这一条命令会依次做完四件事，每步都会打印结果：

| 步骤 | 做什么 |
|---|---|
| ① 安装 | 写配置 + 部署 `~/Applications/PrintAgent.app` + 注册开机自启 |
| ② 打印通道 | 让打印由系统打印服务发起（macOS 15+ 会拦直连，这一步是必须的） |
| ③ 合盖继续运行 | 关掉系统的合盖睡眠开关（会问一次管理员密码）——**合盖放置的收银机必须做** |
| ④ 体检 | 一次查完配置/自启动/通道/防睡眠/云端，并给出结论 |

装好后：程序是 `~/Applications/PrintAgent.app`，配置与日志在
`~/Library/Application Support/PrintAgent/`（macOS 不建议把数据写进 App 里）。
这些路径脚本结束时会直接打印出来，不用记。

只想装、不做后面几步：`./install.sh --minimal`。
不想每次都设置「合盖继续运行」：`./install.sh --no-lid 后台地址 令牌`。

> **出任何问题，先跑这一条**（它会一次查完并直接告诉您该敲什么命令）：
>
> ```bash
> "$HOME/Applications/PrintAgent.app/Contents/MacOS/print-agent" --doctor
> ```

### Linux（小主机 / 树莓派）

```bash
sudo ./install.sh   # 按提示输入后台地址和令牌(systemd 自启动需要 root)
sudo systemctl status print-agent   # 或 ./p.sh 查看状态
```

## Mac 合上盖子还想继续打单

如果这台 Mac 要合着盖子放在收银台下，需要做**两件事**，缺一件都不行：

| # | 做什么 | 怎么做 |
|---|---|---|
| ① | 挡住「闲着就睡」 | 装的时候问「是否需要在 Mac 合盖后继续工作」，选 **y**（重装时选 y 也行，或先设 `PRINT_AGENT_NO_SLEEP=1` 再装） |
| ② | 关掉「合盖就睡」 | 执行 `./install.sh` 时会提示并代您设置（需要管理员密码）；也可手动：`sudo pmset -a disablesleep 1` |

**为什么第 ② 步不能省**：macOS 的「合盖睡眠」是一个独立的开关，**第 ① 步的防睡眠挡不住它**，
所以只做 ① 的话，盖子一合上系统照样睡、代理照样停。这也是它容易漏掉的原因。

装完可以随时用这一条确认：

```bash
./p.sh
```

看「合盖/睡眠」一节：

- `合盖睡眠开关: 已关闭(合盖不睡)` + `caffeinate: … -i -s …` → 两件事都到位，合盖也能打单；
- 写着「未关闭」→ 按上面第 ② 步补一下；
- 没有 caffeinate 那几行 → 按上面第 ① 步重装。

**请务必给 Mac 接着电源**：合盖运行会一直耗电，机身也会比较热，请放在通风处。
要改回「合盖就睡」，执行 `sudo pmset -a disablesleep 0` 即可。

## macOS 打不出小票时先看这一条

macOS 15 起，系统会限制「连接局域网设备」（就是连打印机）这件事，而**开机自动运行的
代理默认拿不到这个许可**。表现是日志里反复写：

```
无法连接打印机 192.168.1.133:9100: dial tcp ...: connect: no route to host
```

这句话跟「打印机没开机」长得一模一样，所以很容易查错方向。**先分清是哪种**：

1. 在这个文件夹里手工执行一次自检（IP 换成本店的打印机）：

```bash
./print-agent-darwin-arm64 --probe 192.168.1.133     # Intel Mac 用 -amd64
```

2. 结果分两种：

| 自检结果 | 说明 | 怎么办 |
|---|---|---|
| 显示「**可达**」 | 网络和打印机都没问题，是系统权限拦下了自启动的代理 | 见下面「办法」 |
| 显示「**不可达**」 | 真的是网络/打印机问题 | 按屏幕提示查：打印机是否开机、IP 有没有变、是否同一网络 |

**办法（推荐第一个）**：

- **办法一：让系统来打印**（一条命令，改一次以后再也不用管）

  执行（IP 换成本店打印机）：

  ```bash
  "$HOME/Applications/PrintAgent.app/Contents/MacOS/print-agent" --setup-cups 192.168.1.133
  ```

  或者干脆重跑一次一键安装（它会把这一步做掉）：`./install.sh --no-lid 后台地址 令牌 192.168.1.133`

  看到最后一行「`[完成] 核对通过:… 代理现在可以经系统打印服务出纸`」就算好了。
  这条命令会自己把打印机加进系统、打开对应开关、重启代理并核对，**不需要管理员密码**，
  重复执行也没问题。好处是以后升级代理、换电脑都不用再授权。

  想确认纸真的能出来（**会各出一张**：直连一张、系统打印服务一张）：

  ```bash
  "$HOME/Applications/PrintAgent.app/Contents/MacOS/print-agent" --probe 192.168.1.133 --probe-print
  ```

  看到「已额外经 CUPS 队列[...] 送出自检页」即成功。不想出纸就把 `--probe-print` 去掉，
  只跑 `--probe 192.168.1.133`，同样能看到队列有没有被找到。

  > 注意 `--probe-print` 不能单独用，必须和 `--probe <打印机IP>` 一起给：
  > 单独用它不会探测打印机，反而会当作正常模式再起一个代理实例（小票会被打两遍）。
  > 程序会直接报错拦住，但别养成这个写法。

- **办法二：给代理开权限**

  执行下面这行打开设置面板，找到「长健农场打印代理」并把开关打开：

  ```bash
  open "x-apple.systempreferences:com.apple.preference.security?Privacy_LocalNetwork"
  ```

  注意：这个权限跟着程序版本走，**升级代理后可能需要再开一次**；也**没法重置**，
  如果开关状态看起来不对，请把这一条留给技术人员处理。

以上两种都不行时，把 `./p.sh` 输出的内容发给技术人员。

## 怎么确认装好了

- 上述「查看状态」脚本/命令里，出现**「已连接云端」**，或运行一次自检（命令在
  `install` 完成时屏幕上有提示，复制执行即可；也可以手动按包内文件名执行）：

```bash
./print-agent-darwin-arm64 --once            # macOS Apple Silicon(Intel Mac 用 -amd64)
./print-agent-linux-amd64 --once             # Linux(树莓派等 ARM 设备用 -arm64)
print-agent-windows-amd64.exe --once         # Windows(在解压文件夹里打开 cmd 执行)
```

- 看到「云端自检通过」就说明链路通了。然后在管理后台打一张测试单，打印机应出纸。

## 日常使用

- **不用管它**：开机自动启动、断网自动重连、打完自动回执；
- 出不了纸时先双击 `p.bat`（或跑 `./p.sh`）看状态与最近日志，重点看是不是「打印机连接失败」；
  不确定**电脑到打印机**通不通，可执行一次自检（`--probe`，把打印机 IP 换成本店的，如 `192.168.1.100`）：

```bash
./print-agent-darwin-arm64 --probe 192.168.1.100      # macOS(Intel Mac 用 -amd64)
./print-agent-linux-amd64 --probe 192.168.1.100       # Linux(树莓派等 ARM 设备用 -arm64)
print-agent-windows-amd64.exe --probe 192.168.1.100   # Windows(在解压文件夹里打开 cmd 执行)
```

  显示「可达」就是这段网络没问题（不会出纸）；显示「不可达」就按屏幕提示检查打印机是否开机、
  IP 有没有变、电脑与打印机是否同一个网络。
- 打印机换 IP 了？到管理后台改打印机配置即可，**本机不用动**。

## 想卸载

一句话：**双击 `uninstall.bat`（Windows）/ 执行 `./uninstall.sh`**，它会停掉代理、取消开机自启、
清理日志与状态文件；`agent.env`（地址和令牌）**默认保留**，重装不用重填。
macOS 上还会一并移除 `~/Applications/PrintAgent.app`。

```bash
sudo ./uninstall.sh          # Linux 需要 sudo
./uninstall.sh --all         # 彻底卸载:额外删掉代理程序和 agent.env(重装要重填令牌)
                             # macOS 上还会清掉 ~/Library/Application Support/PrintAgent
```

产物级命令等价：`<产物文件名> --uninstall`（只移除开机自启，其余什么也不动）。

## 收到「可升级」通知后怎么升级

**推荐：自助升级**（一条命令/双击一个文件，无需重新下载压缩包）：

- Windows：**双击 `upgrade.bat`** → 自动下载、校验、替换并重启，看到「已替换」即完成；
- macOS / Linux：执行 `./upgrade.sh`（Linux 用 `sudo ./upgrade.sh`），完成后按提示执行 `./start.sh`（Linux 为 `sudo systemctl restart print-agent`）。

地址和令牌**不用重填**（旧配置 `agent.env` 会自动沿用），升级后管理端就能看到新版本。

**备选：整包替换**（自助升级不可用时，比如门店网络较差）：

1. Windows 先双击 `stop.bat`（macOS/Linux 先跑 `./stop.sh`）；
2. 用新包里的文件**覆盖**旧文件夹里的同名文件；
3. 重新双击 `start.bat`（或 `./start.sh`）。

## 首次运行的安全提示

代理程序是自研的小工具、未购买商业代码签名证书，因此首次运行会看到系统安全提示：

- **Windows**：弹「Windows 已保护你的电脑」时点**更多信息 → 仍要运行**；之后不会再提示；
- **macOS**：提示「无法验证开发者」时，打开「系统设置 → 隐私与安全性」滑到最下方，
  点**仍要打开**（或右键程序图标选「打开」再确认一次）；之后不会再提示。

如果提示反复出现，请联系技术人员确认压缩包完好（sha256 校验文件在压缩包旁）。

## 常见问题（3 条速查）

| 现象 | 处理 |
|---|---|
| 提示「连接云端失败」 | 检查后台地址是否多写了 `/prod-api` 或结尾斜杠；令牌是否复制完整 |
| 一直「打印机连接失败」 | 电脑和打印机是否同一网络；到管理后台确认打印机 IP 正确。**macOS 上先按上面「macOS 打不出小票时先看这一条」分清是网络问题还是系统权限问题** |
| 装好后没反应 | 先看 `p` 脚本状态与日志最近 15 行，把日志内容发给技术人员。macOS 的日志在 `~/Library/Application Support/PrintAgent/print-agent.log`，`./p.sh` 会自动找到并打印 |
| macOS 升级后又打不出小票了 | 「本地网络」权限跟着程序版本走，升级后可能要重新授权一次；改用「办法一」（`PRINT_AGENT_PRINT_VIA=auto`）则不会有这个问题 |

完整排障表见部署手册 `docs/print-agent.md`（技术人员用）。
